A rebuild of netplan.io with one crash-safety fix: /etc/netplan/*.yaml is written atomically and durably (mkstemp + fsync + rename) instead of an in-place truncate, so an interrupted boot (power loss, reboot, SIGKILL) can no longer leave a 0-byte YAML and break networking. Install libnetplan1 netplan.io netplan-generator python3-netplan.

Use the suite that matches the OS actually installed. trixie is stock Debian (amd64, arm64, armhf (ARMv7), i386, ppc64el, riscv64, s390x). raspbian-trixie is Raspberry Pi OS / Raspbian: arm64 (RPi OS 64-bit) and armhf built as ARMv6 hard-float for the Pi 1 / Zero / Zero W, which Debian's ARMv7 armhf cannot provide.
