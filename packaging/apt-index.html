netplan (welland patched) apt repository

A rebuild of Debian's netplan.io with one crash-safety fix: /etc/netplan/*.yaml is written atomically and durably (mkstemp + fsync + rename) instead of an in-place truncate, so an interrupted boot (power loss, reboot, SIGKILL) can no longer leave a 0-byte YAML and break networking. Source: github.com/mithro/netplan (branch welland-atomic-yaml-write).

Setup (Debian / Raspberry Pi OS trixie, arm64)

sudo install -d -m0755 /etc/apt/keyrings
curl -fsSL https://mithro.github.io/netplan/netplan.gpg \
  | sudo tee /etc/apt/keyrings/netplan-welland.gpg > /dev/null

echo "deb [signed-by=/etc/apt/keyrings/netplan-welland.gpg] https://mithro.github.io/netplan/ ./" \
  | sudo tee /etc/apt/sources.list.d/netplan-welland.list

sudo apt update
sudo apt install libnetplan1 netplan.io netplan-generator python3-netplan
