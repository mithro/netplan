netplan (welland patched) apt repositories

A rebuild of netplan.io with one crash-safety fix: /etc/netplan/*.yaml is written atomically and durably (mkstemp + fsync + rename) instead of an in-place truncate, so an interrupted boot (power loss, reboot, SIGKILL) can no longer leave a 0-byte YAML and break networking. Source: github.com/mithro/netplan.

Use the repo that matches the OS actually installed — stock Debian uses the Debian repo; Raspberry Pi OS / Raspbian uses the Raspbian repo (it carries the ARMv6 build that 32-bit Pi 1/Zero need, which Debian's ARMv7 armhf cannot provide).

Debian trixie

Arches: amd64, arm64, armhf (ARMv7), i386, ppc64el, riscv64, s390x.

sudo install -d -m0755 /etc/apt/keyrings
curl -fsSL https://mithro.github.io/netplan/debian/netplan.gpg \
  | sudo tee /etc/apt/keyrings/netplan-welland.gpg > /dev/null

echo "deb [signed-by=/etc/apt/keyrings/netplan-welland.gpg] https://mithro.github.io/netplan/debian/ ./" \
  | sudo tee /etc/apt/sources.list.d/netplan-welland.list

sudo apt update
sudo apt install libnetplan1 netplan.io netplan-generator python3-netplan

Raspberry Pi OS / Raspbian trixie

Arches: arm64 (RPi OS 64-bit) and armhf (ARMv6 hard-float, Pi 1 / Zero / Zero W).

sudo install -d -m0755 /etc/apt/keyrings
curl -fsSL https://mithro.github.io/netplan/raspbian/netplan.gpg \
  | sudo tee /etc/apt/keyrings/netplan-welland.gpg > /dev/null

echo "deb [signed-by=/etc/apt/keyrings/netplan-welland.gpg] https://mithro.github.io/netplan/raspbian/ ./" \
  | sudo tee /etc/apt/sources.list.d/netplan-welland.list

sudo apt update
sudo apt install libnetplan1 netplan.io netplan-generator python3-netplan
